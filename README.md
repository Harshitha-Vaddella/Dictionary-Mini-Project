
# Dictionary Mini Project

## Project Overview
The Dictionary Mini Project is a menu-driven Python application that allows users to manage words and their meanings easily.

## Features
- Add new words and meanings
- Search for word meanings
- Display all stored words
- Update existing word meanings
- Delete words from the dictionary
- Handle invalid menu choices

## Technologies Used
- Python

## Concepts Used
- Python Dictionaries
- While Loops
- Conditional Statements
- User Input
- Dictionary Methods

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python dictionary_mini_project.py
```
